# NutriTrack

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User requested Java OOP, JavaFX, JDBC, Servlet/JSP, collections, exceptions, file handling and multithreading. The original reference specified Java 17, Tomcat 9, H2 and Maven; the user later requested MySQL, so the current implementation uses MySQL with JDBC.

## Product Purpose
Log Indian food portions, calculate daily nutrients, identify gaps and review weekly history. Provide a working academic project with demonstrable Java concepts.

## Brand Commitments
Preserve the supplied report's UI: grey sidebar, white panels, green actions, compact tables, nutrient cards and weekly bars.

## Capabilities and Constraints
User and admin web roles, food management, CSV imports, CSV reports, background reports. The native JavaFX desktop app exposes the same core user and administrator workflows and shares the Java services and database. Nutrition values are illustrative project data, not medical advice.
